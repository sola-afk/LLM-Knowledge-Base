# Checkin.com

## Overview
Swedish-based platform that uniquely combines KYC/KYB compliance with onboarding conversion optimisation. Unlike pure compliance tools, Checkin.com's core thesis is that smooth UX directly drives revenue — claiming double-digit conversion increases from better verification flows. Covers 165+ countries.

## UX & Design Highlights
- **Conversion-first design** — data-driven UX modules designed to grab and retain user attention through verification
- **Visual workflow builder** — customise onboarding flows with a visual interface
- **Conversion optimisation** — A/B testing and UX analytics built into compliance flows
- **Smooth handoffs** — minimises friction and drop-offs during verification
- **Mobile-first** — SDKs for iOS, Android, and web

## KYB Capabilities
- **Company verification**: Business verification across 165+ countries
- **Document verification**: 14,000+ document types from 190+ countries
- **KYC integration**: Combined KYC and KYB in one flow
- **Compliance**: Designed for fintech, gaming, and e-commerce verticals

## Developer Features
- **SDKs**: iOS, Android, Web
- **APIs**: For deeper integrations and custom data handling
- **Visual workflow builder**: No-code flow configuration
- **Multi-industry**: Fintech, gaming, e-commerce templates

## Jurisdictional Coverage
- 165+ countries for verification
- 190+ countries for document types (14,000+ types)

## Relevance to Kota
Unique conversion-optimisation angle could benefit [[Kota]]'s Platform self-serve onboarding where employer drop-off during KYB is a concern. Visual workflow builder is appealing for the compliance team. However, Checkin.com's KYB depth appears lighter than dedicated KYB providers — may lack deep UBO mapping and registry coverage needed for [[Kota]]'s regulatory obligations. Better suited as a UX layer than a core compliance engine. Minimum monthly commitment is a consideration.
