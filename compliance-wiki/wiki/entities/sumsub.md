# Sumsub

## Overview
Sumsub is a unified verification platform covering KYC, KYB, AML screening, fraud prevention, and transaction monitoring. Known for speed — Auto KYB 2.0 can verify businesses in ~15 seconds using a 500M+ record database.

## KYB Capabilities
- **Company verification**: Automated corporate registry checks across 200+ countries
- **UBO identification**: Cross-checked against 11,000+ independent data sources
- **Sanctions/PEP/Adverse media**: Built-in AML screening with ongoing monitoring
- **Risk scoring**: Unified KYC and KYB risk scoring in one platform
- **Ongoing monitoring**: Continuous re-screening for changes

## Developer Features
- **API**: Full REST API with Auto KYB 2.0 endpoints
- **SDKs**: Web, iOS, Android SDKs
- **Webhooks**: Real-time status updates via `applicantReviewed` webhook
- **No-code builder**: Visual workflow builder for verification flows — customise by country or entity type
- **Sandbox**: Functional sandbox for testing edge cases
- **Integration time**: Not specified

## Jurisdictional Coverage
- **Basic tier**: 200+ countries (cached, normalised data)
- **Advanced tier**: 100+ countries (deeper data)
- **Global tier**: 200+ countries with ownership insights

## Pricing
- 14-day free trial with 50 free checks
- Pay per successful verification only
- Custom enterprise pricing

## Relevance to Kota
Strong candidate for [[Kota]]'s needs. Unified KYC+KYB in one platform could replace [[ComplyAdvantage]] entirely. Auto KYB 2.0 speed suits high-volume Embed flows. Webhook support and SDKs align with API-first requirements. EU/EEA coverage needs validation for all markets Kota operates in.
