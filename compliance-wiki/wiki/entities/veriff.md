# Veriff

## Overview
Estonia-based identity and business verification platform. Supports 12,000+ government-issued document types across 230+ countries and 48 languages. Offers combined KYB, KYC, and AML services for comprehensive compliance coverage.

## KYB Capabilities
- **Company verification**: Cross-checks against global commercial registers and business databases
- **UBO identification**: Surfaces complex ownership structures
- **Sanctions/PEP screening**: Global watchlist screening — instant and automatic
- **Fraud prevention**: Corporate fraud detection
- **Combined KYB+KYC+AML**: Unified compliance stack

## Developer Features
- **API**: REST API
- **SDKs**: iOS, Android, Web
- **No-code**: Zapier integration for no-code workflows
- **Flexible integration**: Multiple methods from full API to no-code

## Jurisdictional Coverage
- 230+ countries and territories
- 12,000+ government-issued document types
- 48 languages supported

## Pricing
- Custom enterprise quotes only
- No public tiers or unit pricing
- Generally considered higher-priced, especially for document IDV with manual review

## Relevance to Kota
Broadest jurisdictional coverage (230+ countries) of any provider reviewed. Estonian origin means strong EU awareness. However, pricing opacity and reportedly higher costs are concerns. Zapier integration is useful for quick prototyping but may not suit [[Kota]]'s production Embed API needs. Combined KYB+KYC could replace [[ComplyAdvantage]].
