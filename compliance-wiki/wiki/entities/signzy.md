# Signzy

## Overview
Signzy offers a marketplace of 340+ modular APIs covering document forensics, KYB, KYC, and UBO analytics. Covers 180+ countries with a drag-and-drop orchestration engine designed for high throughput (million-call-per-hour capacity).

## KYB Capabilities
- **Company verification**: Global corporate registry checks across 180+ countries
- **UBO identification**: Ownership mapping across multi-layered structures, calculates indirect stakes
- **Sanctions/PEP screening**: UBO Check API screens controllers against sanctions/PEP lists
- **Document forensics**: Flags inconsistencies in corporate filings and financial records
- **Audit-ready reports**: Auto-generated compliance reports
- **Ongoing monitoring**: Automatic compliance updates for local regulation changes

## Developer Features
- **API**: 340+ modular APIs — pick and combine as needed
- **Orchestration engine**: Headless, drag-and-drop workflow builder
- **White-label**: Full white-label theming support
- **Throughput**: Million-call-per-hour capacity
- **Integration time**: 2–4 weeks typical
- **No-code**: Drag-and-drop orchestration for non-technical users

## Jurisdictional Coverage
- 180+ countries for UBO verification
- 50 U.S. states for Secretary of State documents
- Multi-jurisdictional corporate registries

## Pricing
- Pay-as-you-go, per-check pricing
- Every API call returning 200 or 404 is metered
- Enterprise custom quotes available
- No public rate transparency

## Relevance to Kota
Modular API approach suits [[Kota]]'s Embed product well — can pick exactly the APIs needed. White-label support is a strong fit. High throughput handles bulk onboarding. However, per-call billing (including 404s) needs careful cost modelling. Integration timeline of 2–4 weeks is reasonable.
